# SecurityGuardPatrol
Security Guard's work helper
---
해당 프로젝트는 경비보안업의 업무 중 하나인 순찰 보조용 프로그램 개발 목적으로 개설되었음  

1. 체크포인트 64개소에 대한 순차 출력  
2. 체크포인트 확인시 다음 체크포인트 어나운스  
3. 다음 체크포인트 안내에 대하여 홀딩시 가는 길에 대한 영상이나 간이지도 팝업 출력  
4. 64개소에 대해 순찰 체크시 마일스톤으로 현황 출력  
5. 메인 화면에는 이전, 현재, 다음 2개소까지 출력  

어플 개발을 위한 간단 ui로 제작  
제작 소요시간은 300분을 넘기지 않을 정도의 약식으로 당일 구현을 목표로함.
