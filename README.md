# Security Guard Patrol

초심자 및 대체 근무자를 위한 순찰 보조 앱입니다.  
체크포인트 기록용 앱이 아니라, 순찰 동선과 다음 위치를 빠르게 확인하기 위한 보조 도구입니다.

## 주요 기능

- 64개 체크포인트 순차 표시
- 이전 / 현재 / 다음 / 다다음 체크포인트 표시
- 체크 / 패스 / 포인트 강제이동 기능
- 체크 기준 진행도 표시
- 패스 개수 별도 표시
- 다음 체크포인트 길게 누르면 상세 설명 팝업 표시
- 체크포인트별 사용자 메모 저장 / 삭제
- 사용자 메모가 있으면 기본 설명보다 우선 표시
- 앱 재실행 후에도 메모 유지

## 화면 구성

- 중앙: 체크포인트 카드 4개
  - 이전
  - 현재
  - 다음
  - 다다음

- 하단: 조작 버튼
  - 패스
  - 체크
  - 포인트 강제이동

- 우측: 마일스톤 패널
  - 진행도
  - 패스 개수
  - 체크포인트별 상태

## 데이터 구조

실제 순찰 데이터는 공개 저장소에 포함하지 않습니다.

- 실제 운영 데이터:
  - `lib/data/checkpoint_data.dart`

위 파일은 실제 운영용 체크포인트 데이터이므로 `.gitignore`에 포함됩니다.

공개용 샘플 데이터는 아래 파일을 참고합니다.

- 샘플 데이터:
  - `lib/data/checkpoint_data.sample.dart`

## 체크포인트 모델

```dart
class Checkpoint {
  final int id;
  final String name;
  final String description;

```

## 사용자 메모

사용자 메모는 `shared_preferences`를 사용하여 기기 내부에 저장됩니다.

- 기본 설명은 유지
- 사용자 메모가 있으면 메모를 우선 표시
- 메모 삭제 시 기본 설명으로 복귀
- 앱 재실행 후에도 메모 유지
- 앱 삭제 시 저장된 메모도 삭제될 수 있음

## 빌드

### 의존성 설치

```bash
flutter pub get
```

### 디버그 실행

```bash
flutter run
```

특정 안드로이드 기기로 실행:

```bash
flutter run -d <device_id>
```

### APK 빌드

일반 APK:

```bash
flutter build apk
```

ABI 분리 APK:

```bash
flutter build apk --split-per-abi
```

갤럭시 등 대부분의 최신 안드로이드 기기는 아래 파일을 사용합니다.

`build/app/outputs/flutter-apk/app-arm64-v8a-release.apk`

## 목적

이 앱은 공식 기록 장치가 아닙니다.  
순찰 기록은 별도 기기로 수행하며, 본 앱은 신입자 또는 동선 미숙자를 위한 안내 보조 도구입니다.

또한 순찰 업무 외에도:

- 반복적인 점검 업무
- 시설 관리 루틴
- 순차 프로세스 작업
- 체크리스트 기반 이동 업무
- 신규 인수인계 업무

등 많은 단계를 반복 수행해야 하는 작업 환경에서도 사용할 수 있도록 설계되었습니다.

핵심 목적은:

- 현재 위치 확인
- 다음 작업 안내
- 진행 상태 시각화
- 반복 작업 피로 감소
- 신규 인원 적응 보조

입니다.
